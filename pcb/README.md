# PCB

75 x 64 x 1.6 mm ESP32 multiple-IO board.

- `source/Gerber_ESP32-multiple-IO_PCB_20210624_2026-11-02.zip` — original
  EasyEDA Gerber/drill export.
- `Gerber_*.G*` — extracted copper, solder-mask, silkscreen, and outline layers.
- `Drill_*.DRL` — plated, non-plated, and via drill files.
- `How-to-order-PCB.txt` — EasyEDA PCB order guide.

The case in [`../case/`](../case/README.md) is fitted to this board's outline
and mounting holes. The non-plated mounting holes are 2.032 mm.
